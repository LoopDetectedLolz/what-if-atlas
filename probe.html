The question this page answers

MapLibre listens to touchstart/touchmove, never Pointer Events. So the plan is to gate panning by calling preventDefault() on a stylus-only touchstart, while drawing from pointermove. No spec says whether WebKit keeps delivering those pointer events afterwards. Test 1 settles it.
